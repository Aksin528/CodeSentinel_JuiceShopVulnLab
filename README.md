# CodeSentinel Juice Shop Vulnerability Lab

This repository contains task submissions for Task 1 of the CodeSentinel Cybersecurity Internship.

## 🔍 Vulnerabilities Covered
1. **SQL Injection** – Login Bypass using `' OR 1=1--`
2. **Reflected XSS** – JavaScript execution via `<iframe>` in Search field

## 📁 Files Included
- `SQL-Injection-Report.md` – Full reproduction steps, impact, and recommendations
- `Stored-XSS-Report.md` – Details on XSS exploit in Search field
- `videos/` – PoC demonstration videos for each vulnerability

## 🛠 Tools Used
- OWASP Juice Shop (via Docker)
- Kali Linux
- Browser Dev Tools
